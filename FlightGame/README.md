# Sky Raider · 飞行器大作战

一个用 **C# + WinForms** 写的纵版飞行射击小游戏，纯 GDI+ 绘制，**无任何第三方依赖**
（音效也是自己用 winmm 做的软件混音，不引 NuGet 包）。

## 运行

- 在 Visual Studio 中打开 `FlightGame.sln`，按 **F5**
- 或命令行：`dotnet run --project FlightGame.csproj`

## 操作（纯键盘）

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动飞行器 |
| 空格 | 发射激光（按住连发） |
| P / Esc | 暂停 / 继续 |
| R | 重新开始 |
| M | 静音开关 |
| 回车 | 菜单开始、结算重开 |

## 关卡流程

每一关是「铺怪 → BOSS 预警 → BOSS 战 → 过关」的循环：

1. **波次阶段**：刷出 `8 + 关卡数×3` 架敌机
2. **BOSS 预警**：红色 WARNING 闪烁 + 警报音
3. **BOSS 战**：大型战舰从上方压入，血条出现在顶部
4. **过关**：击破后掉落 3 个道具，短暂结算后进入下一关

关卡越高，刷怪越快、敌机越快、BOSS 血量和弹速越高。第 2 关起出现**重型敌机**
（紫色，3 点血，会向你打瞄准弹）。

## BOSS 机制

- 血量 `55 + 关卡数 × 40`，左右巡航
- 三种弹幕轮换：
  - **瞄准三连** —— 朝你的方向散射
  - **向下扇形** —— 9 发覆盖式弹幕
  - **天降弹雨** —— 随机位置落下
- 血量降到一半进入 **狂暴**：血条变红、核心变红、开火更快、弹幕数量翻倍

## 道具

击落敌机有 13% 概率掉落，BOSS 必掉 3 个（中间那个固定是加命）。

| 图标 | 道具 | 效果 |
| --- | --- | --- |
| `R` 黄 | 连射 | 12 秒内射速提升约 2.2 倍 |
| `S` 绿 | 散射 | 12 秒内变成五向散射 |
| `O` 蓝 | 护盾 | 10 秒护盾泡，替你挡一次伤害后破碎 |
| `+` 粉 | 加命 | 生命 +1（上限 5） |
| `$` 金 | 分数 | 直接 +500 分 |

生效中的增益会显示在左上角，带剩余时间和进度条。

## 音效

`Audio.cs` 里用 **winmm 的 waveOut** 做实时软件混音，多个音效可以同时响：

- 音色全部是程序合成的（扫频正弦/方波、低通噪声），启动时生成 PCM 到内存
- 6 个缓冲轮转 + 独立混音线程，没有外部音频文件
- 没有可用音频设备时自动静音降级，**不会崩溃**；菜单底部会显示当前音效状态

音效覆盖：射击、敌机爆炸、BOSS 爆炸、受击、护盾破碎、拾取道具、BOSS 警报、过关、游戏结束。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `Program.cs` | 程序入口 |
| `GameForm.cs` | 窗口、主循环（Stopwatch 算 delta time）、键盘输入、静音切换 |
| `GameWorld.cs` | 状态机、关卡流程、BOSS 弹幕、道具掉落、碰撞、粒子 |
| `GameRenderer.cs` | 全部绘制：星空、飞机、BOSS、弹幕、道具、HUD、各种界面 |
| `Audio.cs` | winmm 混音引擎 + 音色合成 |
| `Entities.cs` | Player / Bullet / EnemyBullet / Enemy / Boss / PowerUp / Particle / Star |
| `InputState.cs` | 每帧输入快照 |

## 关于帧率

主循环用 `System.Windows.Forms.Timer`（约 16ms 一跳），并用 `Stopwatch` 计算真实
帧间隔，再对 dt 做上限截断（50ms），避免窗口失焦或断点调试后画面突跳。
